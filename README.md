# <b>Projeto Spring React: Dashboard de Vendas<b>

## Sobre o projeto:

   Projeto da semana <b>Spring React da Dev. Superior 4.0</b>. Este projeto tem por sua vez mostrar gráficos
tabela com dados de vendedores por exemplo, onde representado a taxa de sucesso e vendas totais  respectivamente, dados esses que são importados através do banco de dados.

Os dados da aplicação foram armazenados na nuvem da <b>Heroku</b> e para hospedagem utilizei a Netlify.
